# doppelhand

A double of you at the keyboard. doppelhand captures the Windows screen — full desktop, a window, or a region — works out what is on it, then moves the mouse and types to drive the machine the way a person would.

Status: early. Nothing works yet.

## Planned scope

- Screen capture: full desktop, single window, arbitrary region.
- Understanding: turn a capture into named, clickable targets.
- Input: mouse move, click, drag, scroll, key press, text entry.
- A loop that ties the three together so a goal can be handed over and carried out.
